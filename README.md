# СРСП 4 — Мой магазин

Простое учебное Flutter-приложение: главная, каталог, избранное и профиль.

## Запуск

Проект находится отдельно от `my_app`: `~/Documents/срсп4`.

Открой эту папку как проект Flutter или выполни:

```sh
cd ~/Documents/срсп4
flutter pub get
flutter run -d chrome
```

Для Android/iOS выбери подключённое устройство через `flutter run`.

## Как устроен код

- `lib/main.dart` — запуск, Easy Localization и ScreenUtil с размером 375×812.
- `lib/pages/main_page.dart` — номер вкладки и список избранного. Изменения через `setState`.
- `lib/pages/` — отдельные файлы четырёх страниц.
- `lib/widgets/bottom_bar.dart` — нижнее меню.
- `lib/widgets/product_card.dart` — общая карточка каталога и избранного.
- `lib/models/product.dart` — четыре демонстрационных товара.
- `lib/core/constants/` — основные цвета и стили.
- `assets/translations/` — русские и английские тексты.
- `assets/images/` — локальные картинки товаров, интернет для них не нужен.

## Проверка вручную

1. На главной есть приветствие и две карточки.
2. В каталоге нажми сердечко у товара и открой избранное.
3. Удали товар из избранного — сердечко в каталоге тоже изменится.
4. В профиле выбери английский: подписи и остальные страницы переводятся.
5. Перезапусти приложение: язык сохраняется средствами Easy Localization.
6. Проверь узкое и широкое окно. Списки прокручиваются, размеры используют `.w`, `.h`, `.r`, `.sp`.

Избранное хранится только в памяти. Дополнительные задания с тёмной темой и анимацией не включены.

## Связь с Lecture #4.1

Работа сверена с лекцией `Lecture #4.1.pptx` и требованиями СРСП 4.

| Материал лекции | Где используется в проекте |
| --- | --- |
| Слайды 2–3: Flutter ScreenUtil, `.w`, `.h`, `.r`, `.sp` | Настройка в `lib/main.dart`, адаптивные размеры на страницах и в карточке товара |
| Слайды 4–8: Easy Localization, JSON, `context.setLocale` | `lib/main.dart`, `assets/translations/`, переключатель языка в профиле |
| Слайды 10–14: четыре страницы, индекс страницы и `setState` | `lib/pages/main_page.dart`, четыре отдельных файла страниц, `lib/widgets/bottom_bar.dart` |
| Слайды 15–16: список элементов и сердечки | `lib/pages/catalog_page.dart`, `lib/widgets/product_card.dart`, общий список избранного в `MainPage` |
| Слайды 17–19: `AppColors` и `AppTextStyles` в отдельных файлах | `lib/core/constants/app_colors.dart` и `app_text_styles.dart` |

Для простоты переводы вызываются через строковые ключи, например `'home'.tr(context: context)`, как разрешено в задании. Генерация `LocaleKeys` со слайда 9 не используется. В лекции показаны русский и казахский языки; здесь русский и английский по обязательному требованию СРСП 4.

Нижнее меню сделано стандартным `BottomNavigationBar`, как в задании. Принцип из лекции тот же: нажатие меняет индекс страницы через `setState`. `IndexedStack` сохраняет страницы при переключении вкладок. Сердечко реализовано обычным `IconButton` без дополнительного пакета `like_button`.

## Как коротко объяснить работу

«В `main.dart` я подключил переводы и настроил размер макета 375×812. ScreenUtil адаптирует размеры элементов и текста. У каждой вкладки свой файл. Номер вкладки и список избранного хранятся в `MainPage`, а `setState` обновляет экран после нажатия. Тексты берутся из JSON, язык меняется в профиле. Цвета и стили вынесены в отдельные классы, чтобы использовать их на разных страницах».
